🚀 ChainForge - Local Development

Welcome to the local development server for ChainForge.

✅ Server is running!

You can now proceed with setting up the full application.

Next Steps:

  1. Open a new terminal
  2. Navigate to the project directory
  3. Run the Substrate node for blockchain functionality

Start Substrate Node (in a new terminal):

cd "/home/xero/hackathon projects/Cross-Chain-Gaming-Identity-Asset-Vault"
cargo install contracts-node --git https://github.com/paritytech/substrate-contracts-node.git --tag v0.34.0 --force --locked
substrate-contracts-node --dev

Build and Deploy Contract (in another terminal):

cd "/home/xero/hackathon projects/Cross-Chain-Gaming-Identity-Asset-Vault/contracts/gamer_profile"
cargo +nightly contract build
# Then use Contracts UI at https://contracts-ui.substrate.io/
